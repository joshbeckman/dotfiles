We wanted to provide an update about export retries. There was a situation where exports which had a temporary storage error would fail and customers had to start over. We have now made a change as of September 3. An export retries temporary storage errors up to two times. Permanent validation errors still fail immediately. This applies to exports created after September 3. Existing failed exports are not restarted. If an export still fails, download its error report and contact support with export ID.
